# Citation and manuscript wording

## Software citation

Use the metadata in `CITATION.cff` after the final author list, repository URL, release version, publication date and DOI have been completed. A tagged GitHub Release can be archived by Zenodo to obtain a version DOI and a concept DOI.

## Methods statement

Suggested wording:

> TSA56 sample sequences were added to a locked 60-reference alignment using MAFFT v7.525 (`--add --keeplength`). Maximum-likelihood phylogenetic inference was performed with IQ-TREE v3.0.1 using the TVM+F+R5 model, 1,000 ultrafast bootstrap replicates, BNNI optimization and device-adaptive thread allocation. Genotypes were assigned from reference-anchored phylogenetic evidence; similarity comparison was not used for genotype determination.

Adapt this statement to the manuscript's exact validation design and cite the MAFFT, IQ-TREE and reference-genotyping sources.

## Code availability statement

Suggested wording:

> The bilingual Orientia TSA56 Phylogenetic Typing V1 software, fixed reference manifest, container configuration, documentation and tests are available from the versioned GitHub repository and archived release cited in this article. The software is downloaded and run locally; uploaded sequences are not transmitted to a public analysis server.

Insert the final repository/DOI citation in the journal's required style. Do not claim diagnostic or clinical validation beyond the study's evidence.
