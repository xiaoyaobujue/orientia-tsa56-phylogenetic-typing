# 分析方法

## 适用范围

V1.0 公开版用于恙虫东方体（*Orientia tsutsugamushi*）TSA56 系统发育分型。服务器端固定全部系统发育推断参数，用户不能选择快速分型、相似性判型、placement 判型或其他替代方法。

## AB1 预处理

单向或双向 AB1 峰图按固定默认值 Q35、最小重叠 80 bp 进行质控。355 条 TSA56 参考库仅用于判断测序方向和辅助拼接质控，不能写入最终基因型字段。双向序列分别定向，达到质量和重叠要求后拼接。

## 固定参考比对

将通过质控的样本加入固定 60 条参考序列比对，不改变参考比对长度：

```text
mafft --add samples.fasta --keeplength 60ref_151-850.fas
```

固定参考包含 60 条序列、898 个比对列；SHA-256 记录在 `data/manifest.json`，程序导入时校验。

## 系统发育推断

样本与固定参考的联合比对使用：

```text
iqtree -s alignment.fasta -m TVM+F+R5 -bb 1000 -T AUTO -bnni
```

`-T AUTO` 只是计算资源设置，由 IQ-TREE 根据当前数据和电脑选择 CPU 核心；它不改变固定模型、bootstrap 次数、BNNI、参考库或判型规则。高级用户可用 `PHYLO_PUBLIC_IQTREE_THREADS` 设置正整数限制，实际值会记录在报告和 API 配置中。

已验证工具版本为 MAFFT 7.525、IQ-TREE 3.0.1。系统保留联合比对、treefile、IQ-TREE 报告/日志、bootstrap 树集、一致树、中点定根展示树和 SVG。

## 基因型判定

基因型根据样本相对于人工整理参考锚点的树拓扑判定。自动接受要求参考锚定拓扑唯一、达到配置的 UFBoot 标准，并与参考衍生的树枝距离和分离间隔范围一致。模糊、证据不一致、参考锚点不足或支持度不足的样本标记为人工复核。

最近参考距离属于系统发育树的辅助证据，不是独立相似性分类器。距离阈值来源于参考数据，尚未完成留一参考外部验证；机器可读结果会保留这一限制。

## 定根与解释

定根和末端排序仅用于一致展示，不产生基因型结论。科研解释应同时检查未定根 IQ-TREE 拓扑、分支支持度、参考组成、序列质量和完整原始结果文件。
