# 隐私与安全

- V1.0 在用户电脑本地接受匿名科研任务，不需要账户。
- 任务 ID 使用随机 128 位标识，下载文件只能从校验后的任务输出目录提供。
- 上传限制为预期扩展名/内容，每个文件不超过 8 MB。
- 默认一次只运行一个系统发育任务，IQ-TREE 使用设备自适应 `-T AUTO`。
- 上传和结果默认 24 小时后清理；清理只处理经过规则校验的匿名任务目录。
- API 设置禁止 MIME 猜测、禁止嵌入、同源引用、受限权限和 no-store 响应头。
- Docker Compose 默认只绑定 `127.0.0.1`。除非明确需要并完成安全配置，不要改为 `0.0.0.0`。

本工具不用于受保护健康信息。上传前必须使用假名化研究编号并删除直接身份信息。任何可通过网络访问的部署均需另行进行安全、隐私和合规审查。
