# 引用与论文写法

## 软件引用

正式作者、仓库地址、release 版本、发布日期和 DOI 补齐后，按 `CITATION.cff` 提供的元数据引用。带标签的 GitHub Release 可由 Zenodo 归档，获得版本 DOI 和总版本 DOI。

## Methods 建议文字

> TSA56 样本序列使用 MAFFT v7.525 的 `--add --keeplength` 加入固定 60 条参考序列比对。使用 IQ-TREE v3.0.1、TVM+F+R5 模型、1,000 次 ultrafast bootstrap、BNNI 优化和设备自适应线程进行最大似然系统发育推断。基因型根据参考锚定的系统发育证据判定；相似性比较不用于基因型判定。

正式论文应按实际验证设计调整文字，并引用 MAFFT、IQ-TREE 和参考分型来源。

## Code Availability 建议文字

> 本文使用的中英文恙虫东方体 TSA56 系统发育分型 V1 软件、固定参考清单、容器配置、说明和测试可通过论文引用的带版本 GitHub 仓库及归档 release 获得。软件由用户下载后在本地运行，上传序列不会发送至公共分析服务器。

按期刊格式插入最终仓库和 DOI 引用，不得超出研究证据宣称诊断或临床有效性。
