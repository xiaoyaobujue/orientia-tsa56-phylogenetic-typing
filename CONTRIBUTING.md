# Contributing

Changes to the scientific workflow require an explicit versioned proposal, reference checksum review, automated tests and an updated validation record. A pull request must not silently change the fixed reference, alignment arguments, IQ-TREE model/bootstrap/BNNI settings or genotype decision rule. CPU allocation defaults to `-T AUTO`; a local integer override is a runtime resource setting and must remain reportable.

Do not submit patient data, unpublished sample files, local results, service logs, machine-specific paths or credentials. Use synthetic or reference-derived test material.
